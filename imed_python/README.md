# IMED standalone PySide6 port

From the workspace root, run `python -m imed_python`. Use **Import MATLAB (.mat)** to open a saved IMED case with its experiments, process inputs, solubility, fitted models, and mesh settings. You can also open a file at startup with `python -m imed_python "C:\path\to\case.mat"`. Use the MATLAB `-v7` save format for import.

The landing screen follows MATLAB's `ControlPanel.m` and uses its workflow diagram. **Edit experimental inputs** creates and edits experiments, and **Review saved inputs** inspects their stored values. Paste Excel rows into the selected cell with **Paste from Excel** or Ctrl+V. Each profile table supports adding and deleting rows. The process and solubility tables accept pasted numeric values in the displayed field order. **Generate candidate model** creates an unfitted model from selected mechanisms with editable starting values, bounds and estimation flags. **Model Configurations** lets you edit parameter values, bounds, and estimation flags. Saving in that dialog applies changes to the current session and clears fitted results for changed models. Use **Save Model** on the control panel to write a new MAT file. **Digital Design** opens the forward simulator for the loaded case. Select an experiment and model and click **Simulate** to see count, concentration, the final volume-based size distribution, and D10/D50/D90. The percentile tab compares model predictions with measured values when the case contains them. For direct access, run `python -m imed_python --simulate`.

Digital Design also has **Experiment comparison** and **Size summary** buttons. **Simulate all experiments** evaluates the selected model across the loaded case. Experiment comparison gives each experiment a row with measured/predicted D10/D50/D90, concentration and counts, including MAPE. Size summary overlays the three size quantiles across experiments and reports mean ± population SD of their percentage errors. Both windows share saved evaluations, export MAPE tables, show PBM runtime, and support cancellation. MAPE uses the measured denominator and excludes zero measurements. Count-shape MAPE compares peak-normalized traces because measured FBRM counts and predicted particle number density have different units. The raw count traces use separate axes. Size summary offers the supplied six-experiment PAX absolute error-bar preset and the RSV relative-error preset, with error bars off initially. The presets are selectable reference values from the supplied plotting script.

The control panel's **PBM solver** selector applies to Digital Design, Parameter Estimation, Model Discrimination, and D-Optimal Design. **JAX PBM (Auto)** uses JAX's default device. **JAX PBM (CPU)** and **JAX PBM (GPU)** select a device explicitly. The GPU option reports a setup error if JAX cannot initialize a GPU. Digital Design also lets you choose a solver for a single simulation and reports the device used. JAX compiles on the first run for a given input shape and uses float64. **SciPy PBM** is the default for cases without a saved solver choice.

For GPU use on Windows, set up [WSL2 with Linux GUI support](https://learn.microsoft.com/en-us/windows/wsl/tutorials/gui-apps) and follow the [JAX installation instructions](https://docs.jax.dev/en/latest/installation.html) for your GPU and driver. In a WSL2 Python environment, install NumPy, SciPy, PySide6 and Diffrax alongside GPU-enabled JAX. Run `python -c "import jax; print(jax.devices('gpu'))"` to verify that JAX sees the GPU, then launch `python -m imed_python` from the workspace root and select **JAX PBM (GPU)**. The packaged Windows app uses the native SciPy solvers.

With a SciPy solver selected, **CPU workers** controls how many candidate simulations can run at once during the global search in Parameter Estimation, Model Discrimination, and D-Optimal Design. The default of one uses the serial search. With multiple workers, differential evolution updates its best candidate once per generation, so it may take a different search path. Local least-squares refinement and individual Digital Design simulations each run as a single job. The headless `fit_model` and `optimize_recipe` functions accept a `workers` argument for the same parallel search.

The simulator uses fitted parameters where present and fixed values from the parameter table. The headless entry point, `imed_python.solver.simulate`, accepts a 35-element IMED parameter vector, experiment and process dictionaries, solubility coefficients, and optional grid settings. Set `settings["Numerics"] = "jax"` and optionally `settings["JaxDevice"]` to `"cpu"` or `"gpu"`. JAX mode uses a step limit, configurable with `settings["MaxSteps"]`. The JAX solver was tested with JAX 0.10.1 and Diffrax 0.7.2 on CPU.

**Parameter Estimation** runs one or all models against the loaded experiments. Set count, concentration, and size weights and choose full CSD or D10/D50/D90 for the size term. The optimizer uses SciPy differential evolution followed by bounded least squares. Each model automatically receives local 95% parameter intervals from its final covariance. The result area displays the interval table and a **Covariance** heatmap for the selected model. **Calculate parameter CIs** opens the same calculator before or after fitting. If covariance cannot be estimated, the fit remains available with the reason shown in the CI column. Apply fitted parameters to use them in the rest of IMED.

The inline covariance heatmap fills its available panel. **Open covariance window** opens a larger, resizable view with a plot toolbar for zoom and figure export. The same view is available from PE details and the standalone CI calculator.

The PE log reports PBM simulation time for the latest objective evaluation and a final count, total compute time, mean time per run, and fit wall time. Parallel-worker compute times are summed across workers. The QMOM comparison shows separate PBM and QMOM solve times and total elapsed time, also retained in its checkpoint data and CSV export.

When **Size terms** is **D10 D50 D90**, **Size samples** chooses **Final D10 / D50 / D90** or **All recorded D10 / D50 / D90 trends**. Trend fitting compares each recorded size channel at its measured times. The size weight is normalized by the total number of size observations. Final-only experiments remain usable as final observations in trend mode. The selected mode is retained in PE results, applied settings and checkpoints, and the standalone CI calculator can use the same trend objective.

**Parameter Uncertainty** is available under **IMED → Modeling workflow** once a model and experimental data are loaded. In **Model Configurations**, check **Estimate** for the continuous parameters to include and give them distinct bounds. Choose a model, measured response weights, and confidence level (95% by default), then click **Calculate intervals**. The dialog uses fitted values if present or the configured nominal values otherwise. It evaluates sensitivities without optimizing or changing the parameters. The results show the standard error and interval limits on the parameter's displayed scale, including log scale where applicable. Use **Export CSV** to save the table.

The default **MATLAB IMED** convention follows the original `ParameterEst/+utils/run_parameter_estimation.m` covariance scaling and `ParameterEst/ParaView.m` interval display. Covariance is scaled by residual sum of squares divided by residual rows minus fitted parameters. Limits use the two-sided normal multiplier, approximately 1.96 for 95% confidence. The calculator uses the PE weighted residual layout and respects the loaded PBM tolerances. The optional **Student t (measured points)** convention retains finite-sample intervals with CSD compared at measured sizes, one degree of freedom removed per normalized trace, and initial concentration excluded.

Intervals are calculated for continuous kinetic parameters. Model selector switches and parameters fixed by equal bounds are excluded from the manual sensitivity calculation. The intervals assume a useful local fit and are provisional at nominal values or when fitting stops at an evaluation limit. Bounds constrain sensitivity trials, while reported intervals can extend outside them. PBM trajectories and sensitivities also depend on the selected numerical scheme.

Under **Parameter Estimation → Advanced Settings**, click **Compare PBM with QMOM** beside the Lmax and bin settings. Choose the **Model** and **Experiment** to test, adjust **Lmax** and **Bins**, then click **Run comparison**. The comparison uses the current parameter values and those mesh settings. Its five plot tabs show dissolved and crystalline API mass with total balance drift, M0–M5, PBM volume-based D10/D50/D90, concentration and solubility with temperature and antisolvent fraction, and the final volume-based distribution. Crystalline mass includes seed crystals and any PBM overflow. **Export trajectories CSV** saves the numerical histories. Each plot toolbar can save its figure.

QMOM evolves six moments with up to three quadrature nodes. Its D10/D50/D90 and final distribution use the resulting volume-weighted nodes. These provide a discrete approximation of the size distribution. QMOM reports a reason if it encounters an unsupported state or a size-domain boundary. Completed comparisons, the selected experiment, mesh settings, and plot data are retained in the checkpoint and restored when compatible with the current inputs.

**Model reliability**, below **Digital Design**, propagates the current model's CI covariance through the PBM. Choose a model, experiment, number of draws, and random seed. Parameters are sampled jointly from a multivariate normal distribution in their displayed units, including log-rate parameters. Current standalone CIs work before PE. Applied fits with covariance can also supply the distribution. The plots show parameter draws, D10/D50/D90 and concentration evolution, FBRM predictions, final prediction distributions, and absolute and relative size-error histograms. The evolution plots show pointwise central 95% and 99% model uncertainty intervals from the successful draws. Relative error follows the supplied MATLAB script, `100*(predicted-measured)/predicted`. The black line marks nominal error at the last selected observation. The symmetric error limits are `±prctile(abs(error), [95,99])`, using MATLAB's midpoint percentile convention.

Set **Allowed absolute relative error** to assess reliability. The initial limit is 5%. **Assess** offers **All samples** and **Final samples**. All samples compares every measured size time point for each draw. Final samples uses the last measured value of each quantile and is the default when a saved assessment choice is absent. With ten draws, Final samples gives ten comparisons per quantile, thirty across D10/D50/D90. Saved files restore their selected mode. The Reliability tab reports the fraction of size-error comparisons within the limit and the fraction of complete draws passing every selected point. Joint model reliability requires D10, D50 and D90 to pass in the same draw. Failed simulations and nonfinite predicted sizes count as failures. Missing measured quantiles make joint reliability unavailable. The displayed 95% exact binomial interval uses the independent draw count. Ten passing draws give a joint estimate of 100% with a 69.15–100% sampling interval. Changing the threshold or assessment scope reuses the saved predictions.

The error plots display their comparison and draw counts. Tiny error limits use significant digits. Each error tab has independent **X lower** and **X upper** fields, **Apply x limits**, and **Auto**. The limits apply to all three size panels in that tab and accept scientific notation. The relative-error plot shades the allowed-error region. **Export reliability CSV** saves the numerical assessment, and **Export samples CSV** includes each draw's pass flags. Threshold, assessment scope, results, and plot limits are retained in **Save Model** checkpoints.

**FBRM prediction** shows measured counts, the nominal prediction, the sample median, and pointwise 95% and 99% model uncertainty intervals. A fixed proportional scale converts PBM particle number density into FBRM counts. It is fitted by least squares through the origin against the selected experiment's nominal simulation. The plot shows the scale. Parameter and selected operating-condition uncertainty are propagated with that scale held fixed. Calibration uncertainty and measurement noise are outside these model intervals. Cases without usable measured counts display PBM particle number density. Saved results from earlier versions retain their existing plots and can generate the count intervals on the next run. **Export model intervals CSV** saves the median and interval bounds for the size quantiles, concentration, and available FBRM/count prediction.

**Probabilistic sensitivity**, below **Model reliability**, can vary operating conditions, parameter CI uncertainty, or both. Operating conditions use editable independent uniform ranges. The initial ranges are temperature offset −2 to +2 °C, AS feed and seed mass multipliers 0.9 to 1.1, initial concentration multiplier 0.95 to 1.05, and profile duration multiplier 0.9 to 1.1. Temperature is selected initially. Parameter uncertainty can be selected when covariance is available. The PRCC heatmap relates each varying input to final D10/D50/D90, concentration and FBRM/count while controlling the other sampled inputs. It describes monotonic conditional association. Unavailable cells identify too few draws, constant inputs, constant outputs or effects that cannot be identified separately. Each output uses the draws with a finite prediction for that output. Evolution plots align duration-varied profiles by fractional progress. Their model uncertainty bands summarize variation from the selected inputs at each position in the profile. With parameter sampling disabled, the bands come from the selected operating-condition ranges.

The sensitivity window starts at 720 pixels high and arranges the operating-condition ranges in two groups to leave more room for the plots.

Both probabilistic windows report nominal simulation, completed/successful/failed draws, and summarizing. Both use **CPU workers** with SciPy, support cancellation, and export draw values, success status, final predictions, and failure reasons as CSV. Joint normal draws can extend beyond configured fitting bounds. Failed simulations are counted explicitly and excluded from prediction plots. Propagated intervals summarize the successful draws. **Save Model** retains all draws, covariance, condition ranges, random seed, failures, and prediction trajectories. Reopening restores compatible results.

**Save Model** saves a complete IMED checkpoint as a MATLAB `.mat` file, including current input data, model configurations, solver and objective settings, fitted results, CI values, covariance matrices, and completed Python workflow steps. It also supports cases imported from CrystaLoop recordings. Original MATLAB variables are preserved when a source MAT file exists. Reopen the checkpoint with **Import MATLAB (.mat)**. Saved PE results, compatible CI results, forward-simulation plots, and recommended design recipes are restored in their corresponding dialogs. **Executed steps** lists completed operations. Results from different model values, input data, or solver settings remain in the history but are not presented as current results.

**Model Discrimination** requires at least two fitted models. It searches for a recipe that maximizes weighted pairwise separation between predicted responses. **D-Optimal Design** requires a fitted model with finite parameter covariance and at least two selected responses. It searches for a recipe that maximizes the log determinant of the sensitivity-based Fisher information matrix. Both can export the recommended profiles and seed mass as CSV.

The design search supports one temperature ramp and one antisolvent pulse. Thermocycling, MATLAB design-history persistence, and Digital Design sensitivity analysis are pending. PE reports per-model fit diagnostics but does not yet reproduce the MATLAB cross-model F and t test decisions. Numerical parity with MATLAB is still unverified.

Run `python -m unittest imed_python.test_solver imed_python.test_estimation imed_python.test_uncertainty imed_python.test_session imed_python.test_design imed_python.test_comparison imed_python.test_probabilistic` for the local calculation checks.

The [PBM numerical validation](validation/README.md) includes the independent QMOM implementation, a nine-case grid-refinement study, and the saved comparison trajectories.

For archived MATLAB fits, **Archived MATLAB PE** uses the historical parameter-estimation discretization and an ode45-style step controller. The mode retains the historical mass-balance defects. **SciPy PBM** and **JAX PBM** use the corrected conservative discretization. Parameters calibrated with one scheme may need refitting for use with the other.

The archive comparison runner recovers MATLAB predictions from saved weighted residuals and writes one summary row per model, experiment, and solver mode. It reports count shape after peak normalization, concentration at the recorded times, and final volume-based D10/D50/D90.

```powershell
python -m imed_python.validation.compare_matlab "C:\path\to\case.mat" --output comparison
```

## CrystalLoop campaign recordings

Use **Import CrystalLoop** and select the campaign directory containing `definition.json` and the individual run folders. IMED reads `execution.csv` for the completed runs whose recorder has finished writing. Select the runs, confirm the recorded channel mappings, and enter the process inputs shared by those runs. Use the elapsed-time window to exclude charging, pump return, or cleaning. Import groups with different initial conditions separately.

The importer reads temperature, concentration, FBRM counts, D10/D50/D90 and the antisolvent scale directly from the CSVs. Set the concentration multiplier to convert recorded readings to g/g solution. For example, use 0.01 for a mass percentage. Supply an initial concentration explicitly if the instrument lacks a reading at the start. IMED retains the size percentile histories and takes the last simultaneous, ordered triplet as the final size measurement. It leaves the full measured size distribution empty.

For antisolvent, select the direction appropriate to the scale. A reservoir scale normally decreases. IMED median-filters the scale, estimates nondecreasing added mass, and derives a nonnegative feed profile in g/s with the same integrated mass. **Experimental Input → Recorded channels** shows the imported readings, the added mass estimate, and the derived feed.

For modeling, open a model case with the appropriate kinetics and solubility first, then import the campaign. The import replaces the experimental records for the session and retains the model configuration. CSV campaign import requires no MAT conversion. **Save Model** writes the imported inputs and completed IMED workflow to a MATLAB checkpoint.
