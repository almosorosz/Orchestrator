# Synthetic CrystalLoop campaign for IMED

These two 60-second recordings are generated by the IMED PBM. They contain synthetic temperature,
concentration, FBRM count proxy, volume-based D10/D50/D90, and reservoir scale measurements.
Missing D-values at startup indicate that the unseeded model has no crystals yet.
The moderate and higher feed runs add 0.750 g and 1.350 g of antisolvent, respectively.
The temperature and feed schedules are synthetic. The solubility and process inputs use the
simple nucleation example bundled with IMED.

In CrystalLoop, open **Plots**, use **Browse…**, and select this campaign folder.
In IMED, open **Upload Model** and load **simple_nucleation.mat** from the examples directory
to populate the modeling settings, then use **Import CrystalLoop** and select this folder.
Keep the default channel mappings, a concentration multiplier of 1, and the decreasing
reservoir scale direction. The process template uses 10 g solvent, zero initial
antisolvent, and zero seed. Open **Experimental Input → Recorded channels** to plot the data.
